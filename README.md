# 小鲸鱼 · 可内接任意模型的手机语音助手

> 喊一声「小鲸鱼」，它听懂你说话，然后替你操作手机。
> **唤醒词与语音识别全部离线运行**，只有转成文字的那句话会发给你自己配置的模型 API。

**⬇️ [下载最新 APK](https://github.com/2277032519z-hub/xiaojingyu/releases/latest)** · [构建流水线](https://github.com/2277032519z-hub/xiaojingyu/actions)

一个可以自己部署、自己接模型的 Android 语音助手：不绑定厂商、不需要云账号、录音不上传。
适合给自己用，也适合给不太会操作智能手机的长辈用。

---

## 特性

- **离线唤醒**：本地识别唤醒词（默认「小鲸鱼」），24 小时待命，不联网、不上传音频
- **离线转写**：整句语音转文字也在本地完成（Vosk 中文模型，42 MB 内置）
- **任意模型**：任何 OpenAI 兼容接口都能接 —— DeepSeek、硅基流动、阿里百炼、OpenAI、本地 Ollama
- **会说话**：系统 TTS 朗读回答，支持中文音色，说完自动回到待命
- **会动手**：通过无障碍服务打开应用、打电话、设闹钟、读屏、点按钮、打字、滚动
- **悬浮气泡**：屏幕底部显示「在听 / 思考中 / 回答」，不打断当前界面
- **极简配置**：一个设置页填完 API 地址、Key、模型名即可用

## 快速开始

### 直接装

从 [Releases](../../releases) 或 Actions 的 Artifacts 下载 `app-debug.apk`，传到手机安装。
> 没有现成安装包时，看下面的「从源码构建」，云端编译约 5–8 分钟。

### 首次设置（约 2 分钟）

1. 打开「小鲸鱼」→ **① 授予权限**：麦克风、通知、悬浮窗、电池白名单、通话、通讯录，逐个允许
2. **② 开启无障碍**：在系统无障碍列表里找到「小鲸鱼 屏幕助手」并打开（决定它能不能动手）
3. 填模型配置 → **保存设置**
4. **③ 开始聆听**，状态显示「● 正在聆听中」即可
5. 在系统设置里允许「自启动 / 后台运行」（国产 ROM 必做）

### 试着说

```

「给张阿姨打电话」
「打开微信」
「设个七点的闹钟」
「看看屏幕上写的什么」
```

## 工作原理

```
┌──────────── 常驻前台服务 WakeService ────────────┐
│                                                   │
│  AudioRecord 16kHz/16bit/单声道                    │
│        │                                          │
│        ├─ 待命：Vosk 语法受限识别器（只听唤醒词）    │
│        │        └─ 命中 → 滴声 + 悬浮气泡          │
│        │                                          │
│        ├─ 聆听：Vosk 整句识别                       │
│        │        └─ 静音 0.9s 或满 12s 结束          │
│        │                                          │
│        ├─ 思考：POST {apiBase}/chat/completions    │
│        │        └─ 流式返回，边收边显示             │
│        │                                          │
│        └─ 执行：回答里的 @act 指令                   │
│                 ├─ open / call / alarm（系统 Intent）│
│                 └─ screen / click / type（无障碍）   │
│                                                   │
│  Android TextToSpeech → 朗读 → 回到待命             │
└───────────────────────────────────────────────────┘
```

模型需要「动手」时，必须先输出一行固定格式的指令，例如：

```json
@act {"do":"call","name":"张阿姨"}
```

指令白名单很窄（`open` `call` `alarm` `timer` `screen` `click` `type` `scroll` `back` `home` `search`），
不在这张表里的动作一律不执行。打电话、花钱、给他人发消息这类不可撤销的操作，提示词要求模型先确认一句。

## 配置模型

设置页三个字段：**API 地址 / Key / 模型名**。常见组合：

| 服务 | API 地址 | 模型名 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` |
| 阿里百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 本地 Ollama | `http://192.168.1.10:11434/v1` | `qwen2.5:7b` |

> 本地/内网地址用的是 http，App 已允许明文流量，接口需与 OpenAI Chat Completions 兼容。

## 语音指令一览

| 你说 | 它做 |
|---|---|
| 打开微信 / 打开相机 / 打开设置 | 启动应用（应用名模糊匹配，内置常用别名） |
| 给张阿姨打电话 | 本地查通讯录 → 直接拨号（无通话权限时打开拨号盘） |
| 设个七点的闹钟 / 十分钟倒计时 | 写入系统闹钟 / 计时器，不经过界面 |
| 看看屏幕上写的什么 | 读取当前窗口文字，再讲给你听 |
| 点「发送」/ 往下翻 / 返回 / 回桌面 | 无障碍直接操作当前界面 |
| 帮我搜一下明天的天气 | 打开浏览器搜索 |

## 权限：为什么每个都需要

| 权限 | 用途 | 不给会怎样 |
|---|---|---|
| `RECORD_AUDIO` | 听唤醒词、听你说话 | 完全无法使用 |
| `FOREGROUND_SERVICE(_MICROPHONE)` | 息屏后仍能监听 | 切到后台就被系统掐断 |
| `POST_NOTIFICATIONS` | 显示常驻通知（系统强制要求） | 服务会被系统终止 |
| `SYSTEM_ALERT_WINDOW` | 显示对话气泡 | 看不到状态提示 |
| `CALL_PHONE` / `READ_CONTACTS` | 「打电话给某人」 | 只能打开拨号盘，不能直接拨 |
| `SET_ALARM` | 「设个闹钟」 | 无法写系统闹钟 |
| 无障碍服务 | 读屏、点击、打字 | 只能回答，不能动手 |
| `RECEIVE_BOOT_COMPLETED` | 开机后提醒你启动 | 重启后要手动打开 App |

## 隐私：什么会上传，什么不会

**不会离开手机的**
- 麦克风里的原始音频（唤醒判定与语音转写都是本地模型）
- 通讯录内容（只在本地按名字查号码）
- 屏幕文字（除非模型明确发 `screen` 指令去读，且读完会作为上下文发给模型用于回答）

**会发给你配置的模型服务的**
- 语音转写出来的那句话
- 最近 4 轮对话上下文
- 你让它读屏时，当前窗口的文字

除此之外没有埋点、没有统计、没有崩溃上报，App 不申请任何账号或登录。

## 唤醒词怎么选

唤醒词走的是「语法受限识别」——只在候选词里挑，比整句识别准，也更省电。选不好会漏唤醒或误唤醒：

- **2–4 个字**最稳，避免生僻字
- 可以写多个变体，逗号分隔，命中任意一个都算唤醒（默认：`小鲸鱼,你好小鲸鱼,你好助手`）
- 经常误唤醒 → 换成更长、更独特的词
- 完全不唤醒 → 换成模型词表里常见的字（如「你好」「助手」）
- 环境嘈杂时离近一点说，或换带麦的耳机

## 从源码构建

三选一，详细步骤（含建 token、上传、报错对照）见 **[上传指南.md](上传指南.md)**。

**GitHub Actions（推荐，手机也能完成）**：推送代码 → Actions 自动构建 → 下载 Artifacts。

**本地**：需要 JDK 17 + Android SDK 34

```bash
./scripts/fetch-model.sh   # 下载 42MB 离线中文模型
gradle assembleDebug       # 产物在 app/build/outputs/apk/debug/
```

**Android Studio**：直接打开工程目录，先跑一次 `scripts/fetch-model.sh`，然后 Run。

## 常见问题

**为什么不做成小程序或网页？**
后台常驻麦克风、息屏监听、无障碍操作都是系统级能力，浏览器和普通网页拿不到。

**会不会很费电？**
唤醒词常驻识别是主要开销，中等水平。可以把唤醒词换成更短的词、或在不用时从通知栏关掉服务。

**断网还能用吗？**
能听、能转文字、能显示出来，但模型回答需要网络（除非接的是本地模型）。

**会不会误打电话？**
播号前模型通常会说一句「这就打给张阿姨」。通讯录里找不到时它会反问号码，不会瞎拨。

**支持多轮对话吗？**
支持最近 4 轮上下文；超出部分会滚动丢弃，保证响应速度。

**支持哪一代 Android？**
minSdk 26（Android 8.0）起，targetSdk 34。国产 ROM 需要放行自启动与后台运行。

## 已知限制

- 代码已在 GitHub Actions 上**编译通过**（每次约 1.5 分钟，APK 约 82 MB），但运行期行为尚未逐项真机验证；遇到问题欢迎提 Issue 贴日志
- 离线识别是 42 MB 小模型，安静环境够用，口音重或嘈杂时会掉字；可自行替换更大的中文模型
- 无障碍读屏依赖目标 App 提供的控件，图片、游戏、自绘界面读不到文字
- 支付、银行等界面本身禁止无障碍点击，这是系统安全设计
- 一次只执行一条指令，「打开微信 → 找到某人 → 发消息」这类多步任务尚不支持
- 常驻麦克风在部分机型会被系统限制为「亮屏时可用」
